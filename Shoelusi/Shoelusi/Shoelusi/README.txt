SHOELUSI — VISUAL BASIC WINDOWS FORMS

1. Ekstrak seluruh ZIP dan buka Shoelusi.sln di Visual Studio 2019 atau yang lebih baru.
2. Gunakan workload .NET Desktop Development dan targeting pack .NET Framework 4.7.2.
3. Jalankan dengan F5. Project memakai target x86 dan Microsoft Jet OLE DB untuk MDB,
   dengan Microsoft ACE OLE DB 16.0/12.0 32-bit sebagai cadangan.

Akun awal
No ID     Nama       Kata sandi    Divisi
SL111     Angga      11111         Staf Gudang
SL222     Bondan     22222         Kasir
SL333     Chiko      33333         Teknisi
SL444     Dandi      44444         Pemilik

Pilih divisi sesuai akun. Klik tombol mata untuk menampilkan atau menyembunyikan
kata sandi. Melalui menu Data Akun,
Pemilik bisa menambah akun, memperbarui akun, mengatur ulang kata sandi, atau
menghapus akun yang belum terhubung dengan data lain. Klik Bersihkan sebelum
menambah akun. Saat mengubah akun, kosongkan isian kata sandi untuk memakai
kata sandi yang tersimpan. Kata sandi mengikuti tipe angka Access (0 sampai
2147483647, tanpa nol di depan). Pengguna yang masih ingat kata sandinya bisa
mengubahnya dari halaman masuk.

Lihat README_DATABASE.txt untuk isi dan lokasi database.
